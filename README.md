# 동화 시장 — 동화고 학생 중고거래 사이트

## 파일
- `index.html` : 사이트 전체 (HTML·CSS·JS 한 파일)
- `logo.png` : 동화고 로고 (로딩 회전 로고, 헤더, 알림 아이콘)
- `app.html` : Claude 미리보기용 (index.html과 내용 같음, 배포에는 안 씀)

## 1. 바로 시연하기 (설정 0분)
`index.html`과 `logo.png`를 같은 폴더에 두고 열면 **시연 모드**로 돌아갑니다.
- 데이터는 그 브라우저(localStorage)에만 저장됩니다.
- 같은 브라우저에서 **탭을 2~3개** 열고, 내 정보 › 시연 모드에서 사용자를 바꾸면
  판매자·구매자·찜한 사람이 실시간으로 채팅/예약/취소하는 모습을 보여 줄 수 있어요.
- 예시 물건은 없어요. "시연 데이터 모두 지우기"로 언제든 비울 수 있어요.

## 2. 진짜로 여러 휴대폰에서 쓰기 (Firebase, 약 15분, 무료)
※ Claude 미리보기 링크는 외부 서버에 연결할 수 없어서 항상 시연 모드예요. 친구들에게는 아래 5번에서 배포한 주소를 주세요.

1. https://console.firebase.google.com → 프로젝트 만들기
2. 빌드 › **Firestore Database** › 데이터베이스 만들기 (테스트 모드)
3. 프로젝트 설정 › 내 앱 › 웹 앱(</>) 추가 → 나오는 `firebaseConfig` 값을 복사
4. `index.html`에서 `const FIREBASE_CONFIG = null;` 을 복사한 값으로 바꾸기
5. 배포: GitHub Pages 또는 https://app.netlify.com/drop 에 폴더를 끌어다 놓기
   (알림은 https 주소에서만 됩니다. 두 곳 모두 https예요)

사진은 Firestore 문서 안에 압축해서 넣습니다(Firebase Storage는 요금제 등록이 필요해서 피함).
테스트 모드 규칙은 30일 뒤 막히니, 수행평가 후 계속 쓰려면 보안 규칙을 바꿔야 해요.

## 기능 정리
| 기능 | 동작 |
|---|---|
| 물건 올리기 | 하단 + 버튼 → 사진(최대 10장), 제목, 카테고리, 설명, 가격, 학번, 이름, 직거래 장소 |
| 나눔 | "나눔하기"를 고르거나 가격에 0을 넣으면 자동으로 나눔 |
| 새 물건 알림 | 종 버튼으로 켠 사람에게 "‹제목›이 등록되었어요" |
| 1:1 채팅 | 상세 화면 "채팅하기" → 판매자와 1:1 방 |
| 거래 약속 | 채팅방 상단에서 날짜·시간 저장 → 10분 전 두 사람에게 알림 |
| 예약중 | 판매자가 채팅방에서 "이 분과 예약하기" → 다른 사람은 채팅 불가, 찜만 가능 |
| 찜 대기열 | 예약이 취소되면 찜을 가장 먼저 누른 사람에게 바로 채팅방이 열림 |
| 거래완료·기록 | 판매자가 채팅방에서 거래완료 → 두 사람의 내 정보 › 거래 기록에 남음, 구매자는 후기 작성 |
| 읽음 표시 | 상대가 아직 안 읽은 내 메시지 왼쪽에 작은 1, 읽으면 사라짐 |
| 카테고리 | 교재·문제집, 도서, 필기구·학용품, 전자기기, 의류·체육복, 생활용품, 스포츠·취미, 기타 |
| 로딩·새로고침 | 로고가 돌아가는 로딩 화면, 상단 작은 새로고침 버튼 |

## 한계 (발표 때 솔직하게)
- **알림**: 사이트가 열려 있을 때(다른 탭에 있어도) 옵니다. 사이트를 완전히 닫은 상태에서
  받으려면 FCM 푸시 + 서버(Cloud Functions, 유료 요금제)가 필요해요.
- **AI 후기 추천**: Claude 미리보기 안에서는 실제 AI(Claude)가 추천합니다. 직접 배포한 사이트에는
  AI 서버가 없어서 거래 정보(물건 이름·가격·장소·판매자)를 넣은 **규칙 기반 추천**으로 바뀝니다.
  API 키를 웹페이지에 넣으면 누구나 훔쳐 쓸 수 있어서 일부러 넣지 않았어요.
- **본인 확인**: 로그인 없이 학번·이름을 직접 입력합니다. 실제 운영하려면 학교 구글 계정 로그인이 필요해요.
